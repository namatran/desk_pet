Desk Pet

A working model of the desk pet Pomodoro timer, built from an Arduino Nano, an LCD1602 and a KY-040 knob. It runs the same logic as desk_pet.ino, so the face, timer, LED and beeps behave like the real build.

Tip: at 60× speed, one minute takes one second, so a 1-minute focus session plus its 5-minute break plays out in about 6 seconds.
